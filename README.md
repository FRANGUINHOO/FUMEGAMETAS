# FUMEGAMETAS
O FumegaMetas é a tua aplicação de acompanhamento de metas em tempo real, criada para te ajudar a manter o foco e cumprir todos os teus prazos com precisão.  Define a tua meta, ajusta a data e a hora limite, e acompanha a contagem regressiva ao segundo. Assim que o tempo esgotar, o alarme sonoro entrará em ação para te avisar que o momento chegou!
